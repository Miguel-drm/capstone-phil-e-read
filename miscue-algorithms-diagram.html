DETECTION PRIORITY & FLOW

1. CORRECT WORD
✓ Exact match or pronunciation variant
→ Advance position, no miscue
2. OMISSION
✓ Word found in look-ahead window (5 positions)
→ Skip omitted words, count miscues
3. REVERSAL
✓ Spoken word matches next word
→ Mark reversal, advance position
4. MISPRONUNCIATION
✓ Similarity ≥ 0.6 to expected word
→ Count miscue, advance position
5. SUBSTITUTION
✓ Similarity < 0.6, not in look-ahead
→ Count miscue, advance position
6. INSERTION
✓ Word not in story at all
→ Count miscue, no position advance
7. REPETITION
✓ Same word spoken twice
→ Count miscue, advance position
8. TRANSPOSITION
✓ Words in wrong order
→ Count miscue, advance position
9. SELF-CORRECTION
✓ Error followed by correction
→ Mark but DON'T count (DepEd standard)
📊 SYSTEM METRICS:
• Real-time speech recognition via Vosk
• Server-side word matching with pronunciation variants
• Look-ahead window: 5 words
• Similarity threshold: 0.6 (Levenshtein distance)
• Supports: English & Tagalog
• Aligned with DepEd Phil-IRI standards
